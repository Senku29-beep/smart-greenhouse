# 🌱 Умная теплица нового поколения
## Автоматизированная система управления микроклиматом для выращивания растений

---

## 📌 О проекте

**Умная теплица** — это полностью автоматизированная система, которая самостоятельно поддерживает оптимальные условия для роста растений. Проект разработан в рамках конкурса в Кванториуме и представляет собой действующий прототип, способный:

- Поливать растения при сухой почве
- Включать подсветку при недостатке естественного света
- Открывать и закрывать форточку для вентиляции
- Отображать все параметры на LCD дисплее
- Самостоятельно восстанавливаться после сбоев

Система построена на платформе **Arduino Uno** с использованием датчиков и исполнительных устройств. Главная особенность — **отказоустойчивость**: при зависании программы аппаратный Watchdog перезагружает контроллер, а дисплей автоматически восстанавливается при сбоях I2C.

## ⚙️ Функциональные возможности (подробное описание)

### 1. Автоматический полив

#### 1.1. Принцип работы
Система полива использует ёмкостный датчик влажности почвы, который измеряет диэлектрическую проницаемость грунта. Чем больше воды в почве, тем выше диэлектрическая проницаемость, тем меньше сопротивление датчика. Arduino считывает аналоговое значение (0-1023) и преобразует его в проценты влажности.

#### 1.2. Датчик влажности почвы
| Параметр | Значение |
|----------|----------|
| Тип | Ёмкостный (не резистивный!) |
| Пин подключения | A0 (аналоговый вход) |
| Рабочее напряжение | 3.3-5.5В |
| Глубина погружения | 3 см (из-за конструктивных ограничений) |

#### 1.3. Калибровка датчика
Калибровка производится экспериментально для каждого типа почвы и глубины погружения:

| Состояние | Значение analogRead() | Влажность (%) |
|-----------|----------------------|----------------|
| Сухая земля (без полива 3 дня) | 554 | 0% |
| Мокрая земля (обильный полив) | 233 | 100% |

#### 1.4. Логика управления насосом

**Условия для ВКЛЮЧЕНИЯ насоса (ДОЛЖНЫ выполняться ВСЕ):**
1. Влажность почвы < 40% (SOIL_DRY) — почва сухая
2. В баке есть вода (waterPresent = true) — защита от сухого хода
3. Прошло 10 минут с последнего полива (WATERING_COOLDOWN = 600000 мс) — защита от частых включений
4. Прошло 1 минута с последнего выключения (MIN_PUMP_OFF_TIME = 60000 мс) — дополнительная защита

**Условия для ВЫКЛЮЧЕНИЯ насоса (ДОСТАТОЧНО ЛЮБОГО):**
1. Прошло 2 секунды работы (PUMP_RUN_TIME = 2000 мс) — нормальное выключение
2. Влажность почвы > 70% (SOIL_WET) — почва стала достаточно влажной
3. Вода закончилась в баке (waterPresent = false) — аварийное отключение
4. Аварийный таймер: насос работает > 30 секунд (MAX_PUMP_RUN_TIME = 30000 мс) — защита от залипания реле

#### 1.5. Исполнительное устройство — насос
| Параметр | Значение |
|----------|----------|
| Рабочее напряжение | 12В |
| Пин управления (через реле) | 3 |
| Тип реле | Обычное (RELAY_INVERTED = false) |
| Сигнал включения | HIGH (5В) |
| Сигнал выключения | LOW (0В) |

#### 1.6. Защита от частых включений
- Минимальный интервал между поливами: 10 минут
- Минимальный простой после выключения: 1 минута
- При сухой почве система ждёт 10 минут, прежде чем включить насос снова

#### 1.7. Фильтрация показаний влажности почвы
Для устранения шумов и случайных выбросов применяется многоступенчатая фильтрация:
1. Усреднение по 10 измерениям
2. Отсечение 2 минимальных и 2 максимальных значений (удаление выбросов)
3. Экспоненциальное сглаживание с коэффициентом 0.15 (85% старого, 15% нового)

### 2. Автоматическое освещение (фитолента)

#### 2.1. Принцип работы
Система освещения использует фоторезистор для измерения уровня естественного света. При наступлении темноты (сумерки) система автоматически включает фитоленту, обеспечивая растениям необходимый для фотосинтеза свет. При появлении достаточного естественного освещения лампа выключается.

#### 2.2. Датчик освещённости — фоторезистор
| Параметр | Значение |
|----------|----------|
| Тип | Фоторезистор 5мм |
| Пин подключения | A1 (аналоговый вход) |
| Рабочее напряжение | 5В |
| Особенность | Датчик инвертированный (темно = 0, светло = 675) |

#### 2.3. Калибровка фоторезистора
| Состояние | Значение analogRead() | Освещённость (%) |
|-----------|----------------------|------------------|
| Полная темнота (рукой накрыли) | 0 | 0% |
| Яркий свет (фонарик) | 675 | 100% |

#### 2.4. Логика управления фитолентой с гистерезисом

**Гистерезис — это разница между порогом включения и выключения**

- **Включение**: освещённость < 30% (LIGHT_ON_THRESHOLD = 30) — реально темно
- **Выключение**: освещённость > 50% (LIGHT_OFF_THRESHOLD = 50) — реально светло
- **Мёртвая зона**: от 30% до 50% — состояние лампы не меняется
- **Разница 20%** предотвращает частое включение/выключение при сумерках

**Почему пороги такие, а не наоборот?** Ваш датчик инвертированный. Мы инвертировали map() так, чтобы:
- реальная темнота → датчик показывает 0% → 0 < 30 → лампа ВКЛ
- реальный свет → датчик показывает 100% → 100 > 50 → лампа ВЫКЛ

#### 2.5. Защита от обратной связи (самое важное!)

**Проблема:** свет от фитоленты попадает на датчик → датчик видит "свет" → лампа выключается → снова темно → лампа включается → бесконечный цикл (лампа моргает, реле щёлкает)

**Решение:** после включения лампы мы ЗАПРЕЩАЕМ её выключение в течение 15 секунд. За это время:
1. Свет лампы перестаёт влиять на датчик (датчик успевает адаптироваться)
2. Или мы успеваем физически экранировать датчик от света лампы

```cpp
static unsigned long lastLampTurnOnTime = 0;
static bool lampJustTurnedOn = false;

if (lightLevelFiltered < LIGHT_ON_THRESHOLD && lampState == false) {
  digitalWrite(LED_GROW_PIN, HIGH);  // Включаем
  lampState = true;
  lastLampTurnOnTime = millis();
  lampJustTurnedOn = true;           // Включаем блокировку выключения
}

if (lampState == true && !lampJustTurnedOn) {
  if (lightLevelFiltered > LIGHT_OFF_THRESHOLD) {
    digitalWrite(LED_GROW_PIN, LOW); // Выключаем
    lampState = false;
  }
}

if (lampJustTurnedOn && (millis() - lastLampTurnOnTime > 15000)) {
  lampJustTurnedOn = false;          // Снимаем блокировку через 15 секунд
}
```

#### 2.6. Исполнительное устройство — фитолента
| Параметр | Значение |
|----------|----------|
| Тип | Светодиодная лента (красный + синий спектр) |
| Рабочее напряжение | 12В |
| Пин управления (через реле) | 5 |
| Тип реле | Обычное (RELAY_INVERTED = false) |
| Сигнал включения | HIGH (5В) |
| Сигнал выключения | LOW (0В) |

#### 2.7. Спектральный состав фитоленты
* Красный свет (640-660 нм) — стимулирует цветение и плодоношение
* Синий свет (430-450 нм) — стимулирует рост вегетативной массы
* Соотношение красного к синему: примерно 3:1

### 3. Автоматическая вентиляция (форточка)
#### 3.1. Принцип работы
Система вентиляции использует датчик температуры DHT11 для контроля микроклимата. При превышении температуры 28°C форточка автоматически открывается, обеспечивая приток свежего воздуха и охлаждение теплицы. При снижении температуры до 26°C форточка закрывается.

#### 3.2. Датчик температуры и влажности DHT11
| Параметр | Значение |
|----------|----------|
| Тип | DHT11 |
| Пин подключения | 2 (цифровой) |
| Рабочее напряжение | 3.3-5.5В |
| Диапазон температур | 0-50°C |
| Точность температуры | ±2°C |
| Диапазон влажности | 20-80% |
| Точность влажности | ±5% |
| Минимальный интервал опроса | 2 секунды |

#### 3.3. Логика управления форточкой с гистерезисом
Пороги температуры:
* Открытие: температура > 28°C (OPEN_TEMP = 28.0)
* Закрытие: температура < 26°C (CLOSE_TEMP = 26.0)
* Мёртвая зона: от 26°C до 28°C — форточка не двигается

Зачем нужен гистерезис? При температуре 27.9°C форточка не будет открываться и закрываться каждую секунду. Она откроется только когда станет 28°C, и закроется когда станет 26°C.

#### 3.4. Защита от дребезга
После каждой команды сервоприводу добавляется задержка delay(500), чтобы дать серво время физически повернуться и избежать конфликта команд.

#### 3.5. Исполнительное устройство — сервопривод SG90
| Параметр | Значение |
|----------|----------|
| Модель | SG90 |
| Рабочее напряжение | 4.8-6.0В |
| Угол поворота | 0-180 градусов |
| Усилие | 1.6 кг/см |
| Пин управления | 4 (цифровой, ШИМ) |
| Угол закрыто | 0° (SERVO_CLOSED) |
| Угол открыто | 90° (SERVO_OPEN) |

Важное замечание: сервопривод SG90 имеет пластиковые шестерни, которые могут изнашиваться при длительной работе. Рекомендуется замена на MG995 (металлические шестерни, усилие 10 кг/см) для промышленной версии.

#### 3.6. Питание сервопривода
Сервопривод требует отдельного стабилизированного источника питания 5В/2А. При питании от шины 5V Arduino возникают просадки напряжения, серво начинает шуметь и работать нестабильно.

Это предотвращает зависание программы при попытке вывести данные на неработающий дисплей.

### 5. Датчик уровня воды (опционально)
#### 5.1. Датчик HCW-M203
| Параметр | Значение |
|----------|----------|
| Тип | Бинарный (HIGH/LOW) |
| Пин сигнала | 6 (цифровой) |
| Пин питания (через реле) | 8 |
| Рабочее напряжение | 12В |
| Логика | HIGH = вода есть, LOW = воды нет |

#### 5.2. Импульсное питание (защита от электролиза)
Проблема: при постоянной подаче 12В на медные провода датчика начинается электролиз:
```cpp
Cu + 2H₂O → Cu(OH)₂↓ + H₂↑
```
Образуется гидроксид меди — синий осадок, который забивает насос и отравляет растения.
Решение: питание подаётся только на время измерения (50 мс), а остальное время датчик обесточен.
```cpp
// Включаем питание датчика через реле
digitalWrite(WATER_SENSOR_RELAY_PIN, LOW);   // LOW = ВКЛ
delay(50);                                    // Ждём стабилизации
bool currentReading = (digitalRead(WATER_SENSOR_PIN) == HIGH);
digitalWrite(WATER_SENSOR_RELAY_PIN, HIGH);  // HIGH = ВЫКЛ
```
Результат: датчик под напряжением только 7 минут в сутки вместо 24 часов — электролиз замедляется в 200 раз!

#### 5.3. Защита от дребезга
При колебаниях уровня воды датчик может быстро менять состояние. Для стабилизации используется задержка 2 секунды:
* Если состояние изменилось, запоминаем время
* Если новое состояние стабильно в течение 2 секунд — принимаем его

### 6. Watchdog (аппаратная автоперезагрузка)
#### 6.1. Что такое Watchdog
Watchdog (сторожевой таймер) — это аппаратный таймер, встроенный в микроконтроллер AVR. Он работает независимо от программы и считает время. Если программа зависла и перестала сбрасывать таймер, через заданное время Watchdog автоматически перезагружает Arduino.

#### 6.2. Настройка Watchdog
```cpp
#include <avr/wdt.h>

void setup() {
  wdt_enable(WDTO_4S);  // таймаут 4 секунды
  // ... остальная инициализация
}

void loop() {
  wdt_reset();          // сброс таймера ("я жив")
  // ... основной код
}
```

#### 6.3. Защита от ложных срабатываний
Длительные операции (инициализация дисплея, задержки) могут превысить таймаут Watchdog. Решение — разбивать длинные задержки на короткие циклы с вызовом wdt_reset():
```cpp
// Вместо delay(3000)
for (int i = 0; i < 30; i++) {
  delay(100);
  wdt_reset();  // сбрасываем watchdog каждые 100 мс
}
```
#### 6.4. Значения таймаута Watchdog
| Константа | Время | Когда использовать |
|----------|----------|----------|
| WDTO_1S | 1 секунда | Для быстрых программ |
| WDTO_2S | 2 секунды | По умолчанию |
| WDTO_4S | 4 секунды | Если есть долгие операции |
| WDTO_8S | 8 секунд | Для очень медленных датчиков |

### 7. Фильтрация и обработка данных
#### 7.1. Экспоненциальное сглаживание (applyFilter)
Принцип: новое_значение = старое_значение × (1 - коэффициент) + сырое_значение × коэффициент
```cpp
float applyFilter(float oldValue, float newValue, float coeff) {
  return oldValue * (1 - coeff) + newValue * coeff;
}
```
Коэффициенты:
* Температура и влажность: 0.3 (30% нового, 70% старого)
* Освещённость: 0.3
* Влажность почвы: 0.15 (более сильное сглаживание, так как почва сохнет/намокает медленно)

#### 7.2. Усреднение с отсечением выбросов (readSoilMoistureStable)
Для датчика влажности почвы делается 10 измерений, затем:
1. Сортировка по возрастанию (пузырьковая сортировка)
2. Отбрасывание 2 минимальных и 2 максимальных значений
3. Вычисление среднего арифметического оставшихся 6 значений
Это устраняет случайные выбросы из-за помех или кратковременных замыканий.

#### Основные настройки (раздел 7)
```cpp
// Временные параметры
const unsigned long PUMP_RUN_TIME = 2000;        // 2 секунды работы насоса
const unsigned long WATERING_COOLDOWN = 600000;  // 10 минут между поливами
const unsigned long MAX_PUMP_RUN_TIME = 30000;   // 30 секунд аварийный таймер

// Калибровка датчика влажности почвы
const int SOIL_DRY_CALIB = 554;  // Значение в сухой земле (0% влажности)

// Калибровка датчика освещённости
const int DARK_VALUE = 0;       // Значение в полной темноте
```

### 🐛 Устранение неполадок (с которыми пришлось столкнуться)
В процессе разработки и отладки проекта возникли следующие проблемы и были найдены их решения:

#### Проблема 1: Дисплей не работал внутри теплицы
* Симптом: дисплей зависал, показывал странные символы или вообще не включался
* Причина: электромагнитные помехи от силовых цепей (фитолента, насос, сервопривод) на длинных проводах I2C
* Решение: вынос дисплея за пределы теплицы, укорачивание проводов SDA/SCL до 20-30 см, уменьшение скорости I2C до 100 кГц
* Результат: дисплей работает стабильно

#### Проблема 2: Watchdog перезагружал Arduino во время инициализации
* Симптом: система постоянно перезагружалась при старте, не доходя до основного цикла
* Причина: длительные задержки (delay(3000), delay(2000)) превышали таймаут watchdog 2 секунды
* Решение: разбивка всех длинных задержек на циклы из коротких пауз (по 100 мс) с вызовом wdt_reset() внутри цикла
* Результат: watchdog перестал срабатывать ложно, система успешно инициализируется

#### Проблема 3: Насос не выключался
* Симптом: насос включался и работал бесконечно
* Причина: переменная pumpStartTime не обновлялась при включении насоса, условие timeCondition никогда не становилось true
* Решение: добавление строки pumpStartTime = currentTime; в блок включения насоса
* Результат: насос работает ровно 2 секунды и выключается

#### Проблема 4: Фитолента моргала (часто включалась и выключалась)
* Симптом: реле фитоленты постоянно щёлкало, лампа мигала
* Причина: свет от фитоленты попадал на датчик освещённости, создавая обратную связь
* Решение: добавление программной блокировки — после включения лампы датчик игнорируется 15 секунд
* Результат: фитолента перестала моргать, работает стабильно

#### Проблема 5: Осадок гидроксида меди в баке с водой
* Симптом: синий осадок на дне бака, насос забивался
* Причина: электролиз медных проводов датчика воды из-за постоянного напряжения 12В
* Решение: замена медных проводов на графитовые стержни (из старых батареек), импульсное питание датчика (включается только на 50 мс при измерении)
* Результат: осадок перестал появляться, датчик работает корректно

#### Проблема 6: Датчик влажности почвы показывал 0% во влажной земле
* Симптом: дисплей показывал 0% влажности, хотя земля была мокрой
* Причина: неправильный порядок аргументов в функции map()
* Решение: исправление map(soilRaw, SOIL_DRY_CALIB, SOIL_WET_CALIB, 0, 100) → map(soilRaw, SOIL_WET_CALIB, SOIL_DRY_CALIB, 0, 100)
* Результат: влажность почвы отображается корректно (сухая → 0%, мокрая → 100%)

#### Проблема 7: Фитолента включалась при свете, а не при темноте
* Симптом: лампа загоралась, когда на датчик падал свет, и гасла в темнот
* Причина: датчик освещённости работал инвертированно
* Решение: инвертирование map() для света: map(lightRaw, DARK_VALUE, BRIGHT_VALUE, 100, 0) → map(lightRaw, DARK_VALUE, BRIGHT_VALUE, 0, 100)
* Результат: фитолента включается в темноте и выключается при свете

#### Проблема 8: Двойное объявление переменной MIN_PUMP_OFF_TIME
* Симптом: ошибка компиляции "redefinition of 'const long unsigned int MIN_PUMP_OFF_TIME'"
* Причина: константа была объявлена дважды в разделе 7
* Решение: удаление дубликата, оставление только одного объявления
* Результат: код успешно компилируется

### 1. Ближайшие улучшения (1-3 месяца)
#### 1.1. Второй датчик влажности почвы
* **Проблема:** при выходе из строя одного датчика или при его некорректной работе система может неправильно определять влажность почвы, что приведёт к гибели растений.
* **Решение:** добавить второй датчик влажности почвы на аналоговый пин A2.
* **Реализация:**
```cpp
#define SOIL_MOISTURE_PIN_1 A0
#define SOIL_MOISTURE_PIN_2 A2

int soilRaw1 = analogRead(SOIL_MOISTURE_PIN_1);
int soilRaw2 = analogRead(SOIL_MOISTURE_PIN_2);
int soilRaw = (soilRaw1 + soilRaw2) / 2;  // Усреднение показаний
```
* **Преимущества:**
* Отказоустойчивость (при выходе одного датчика система продолжает работать)
* Более точные показания (усреднение двух измерений)
* Возможность обнаружить неисправность датчика (при большом расхождении показаний)

### 3. Долгосрочные улучшения (6-12 месяцев)
#### 3.1. БИБЛИОТЕКА РАСТЕНИЙ (Plant Library) — Главная инновация
#### Концепция

Одним из ключевых недостатков существующих умных теплиц является их **жёсткая настройка** под один тип растений или универсальные параметры. Пользователь не может просто выбрать растение и получить автоматически настроенные пороги температуры, влажности, освещённости и полива.

**Идея:** создать встроенную базу данных (библиотеку) растений, где для каждого вида будут прописаны оптимальные условия роста. Пользователь выбирает растение через интерфейс (дисплей + кнопки, Web-интерфейс или приложение), и система автоматически применяет соответствующие настройки.

#### Пример таблицы параметров для библиотеки растений

| Растение | Влажность почвы (мин/макс) | Температура (мин/макс) | Освещённость (PAR) | Влажность воздуха | Полив (л/день) |
|----------|---------------------------|----------------------|--------------------|--------------------|----------------|
| Томаты | 40-70% | 18-28°C | 400-600 мкмоль/м²/с | 60-70% | 3-5 л |
| Огурцы | 50-80% | 20-30°C | 300-500 мкмоль/м²/с | 70-80% | 4-6 л |
| Перец | 40-65% | 18-28°C | 300-500 мкмоль/м²/с | 60-70% | 2-4 л |
| Баклажаны | 45-70% | 20-30°C | 400-600 мкмоль/м²/с | 60-70% | 3-5 л |
| Салат | 50-75% | 15-22°C | 200-300 мкмоль/м²/с | 60-75% | 1-2 л |
| Редис | 40-60% | 10-20°C | 200-300 мкмоль/м²/с | 50-60% | 1-2 л |

#### Реализация в коде (пример на Arduino)

```cpp
// =====================================================================
// БИБЛИОТЕКА РАСТЕНИЙ
// =====================================================================

// Структура, описывающая параметры для одного растения
struct Plant {
  const char* name;           // Название растения
  int soilDry;                // Влажность для включения полива (%)
  int soilWet;                // Влажность для выключения полива (%)
  float tempMin;              // Минимальная температура для форточки (°C)
  float tempMax;              // Максимальная температура для форточки (°C)
  int lightOn;                // Освещённость для включения лампы (%)
  int lightOff;               // Освещённость для выключения лампы (%)
  int airHumidityMin;         // Минимальная влажность воздуха (%)
  int airHumidityMax;         // Максимальная влажность воздуха (%)
  int wateringTime;           // Время работы насоса (мс)
  int wateringInterval;       // Интервал между поливами (мин)
};

// Массив с параметрами для разных растений
const Plant plantDatabase[] = {
  // Название,        soilDry, soilWet, tempMin, tempMax, lightOn, lightOff, airMin, airMax, waterTime, waterInterval
  {"Томаты",          40,      70,      18.0,    28.0,    30,     50,       60,     70,     3000,     720},
  {"Огурцы",          50,      80,      20.0,    30.0,    30,     50,       70,     80,     4000,     480},
  {"Перец",           40,      65,      18.0,    28.0,    30,     50,       60,     70,     2500,     600},
  {"Баклажаны",       45,      70,      20.0,    30.0,    30,     50,       60,     70,     3000,     720},
  {"Салат",           50,      75,      15.0,    22.0,    20,     40,       60,     75,     1500,     360},
  {"Редис",           40,      60,      10.0,    20.0,    20,     40,       50,     60,     1500,     480},
  {"Клубника",        50,      70,      15.0,    25.0,    25,     45,       60,     70,     2000,     600},
  {"Базилик",         40,      60,      18.0,    25.0,    30,     50,       60,     70,     1500,     360},
  {"Петрушка",        40,      60,      15.0,    22.0,    25,     45,       60,     70,     1500,     480},
  {"Укроп",           40,      60,      15.0,    22.0,    25,     45,       60,     70,     1500,     480},
  {"Руккола",         40,     65,      15.0,    22.0,    25,     45,       55,     70,     1500,     480}
};

// Количество растений в базе
const int plantCount = sizeof(plantDatabase) / sizeof(plantDatabase[0]);

// Текущее выбранное растение (индекс в массиве)
int currentPlantIndex = 0;

// Функция применения параметров выбранного растения
void applyPlantSettings(int plantIndex) {
  if (plantIndex < 0 || plantIndex >= plantCount) return;
  
  const Plant& p = plantDatabase[plantIndex];
  
  // Применяем параметры к глобальным настройкам системы
  SOIL_DRY = p.soilDry;
  SOIL_WET = p.soilWet;
  OPEN_TEMP = p.tempMax;
  CLOSE_TEMP = p.tempMin;
  LIGHT_ON_THRESHOLD = p.lightOn;
  LIGHT_OFF_THRESHOLD = p.lightOff;
  PUMP_RUN_TIME = p.wateringTime;
  WATERING_COOLDOWN = (unsigned long)p.wateringInterval * 60000;  // минуты → мс
  
  // Выводим информацию на дисплей
  lcd->clear();
  lcd->setCursor(0, 0);
  lcd->print("Selected: ");
  lcd->print(p.name);
  lcd->setCursor(0, 1);
  lcd->print("Settings applied");
  delay(2000);
  
  Serial.print("Plant selected: ");
  Serial.println(p.name);
}

// Функция выбора растения (по кнопкам или с энкодера)
void selectPlant() {
  // Статическая переменная для запоминания последнего времени нажатия кнопки
  static unsigned long lastButtonPress = 0;
  
  // Если нажата кнопка "вверх" (пин 7)
  if (digitalRead(7) == LOW && millis() - lastButtonPress > 300) {
    lastButtonPress = millis();
    currentPlantIndex++;
    if (currentPlantIndex >= plantCount) currentPlantIndex = 0;
    
    lcd->clear();
    lcd->setCursor(0, 0);
    lcd->print("Plant:");
    lcd->setCursor(0, 1);
    lcd->print(plantDatabase[currentPlantIndex].name);
    delay(500);
  }
  
  // Если нажата кнопка "вниз" (пин 9)
  if (digitalRead(9) == LOW && millis() - lastButtonPress > 300) {
    lastButtonPress = millis();
    currentPlantIndex--;
    if (currentPlantIndex < 0) currentPlantIndex = plantCount - 1;
    
    lcd->clear();
    lcd->setCursor(0, 0);
    lcd->print("Plant:");
    lcd->setCursor(0, 1);
    lcd->print(plantDatabase[currentPlantIndex].name);
    delay(500);
  }
  
  // Если нажата кнопка "выбор" (пин 10)
  if (digitalRead(10) == LOW && millis() - lastButtonPress > 300) {
    lastButtonPress = millis();
    applyPlantSettings(currentPlantIndex);
  }
}
```
