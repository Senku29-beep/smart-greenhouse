# Дорожная карта проекта "Умная теплица нового поколения"

Проект разрабатывается в рамках конкурса в Кванториуме и представляет собой полностью автоматизированную систему управления микроклиматом для выращивания растений.

---

## 📊 Текущий статус проекта

**Версия 1.0.0 — Стабильный релиз (май 2026)**

Проект завершён и готов к демонстрации. Реализованы все основные функции, система отлажена и работает стабильно.

---

## ✅ ВЫПОЛНЕНО (текущая версия)

### Основные функции
- [x] Автоматический полив (насос + датчик влажности почвы)
- [x] Автоматическое освещение (фитолента + фоторезистор)
- [x] Автоматическая вентиляция (сервопривод + DHT11)
- [x] LCD дисплей 16x2 I2C (5 информационных экранов)
- [x] Датчик уровня воды HCW-M203 (опционально)

### Программные алгоритмы
- [x] Экспоненциальное сглаживание (фильтрация шумов датчиков)
- [x] Медианный фильтр для датчика влажности почвы (10 измерений, отсечение выбросов)
- [x] Гистерезис для полива (40% / 70%)
- [x] Гистерезис для форточки (26°C / 28°C)
- [x] Гистерезис для фитоленты (30% / 50%)
- [x] Защита от обратной связи фитоленты (блокировка на 15 секунд)
- [x] Аварийный таймер насоса (30 секунд)
- [x] Защита от частого включения насоса (10 минут между поливами)

### Отказоустойчивость
- [x] Watchdog (аппаратный сторожевой таймер, таймаут 4 секунды)
- [x] Автоматическое восстановление дисплея (3 метода: мягкий сброс, переинициализация, сброс I2C)
- [x] Обработка ошибок DHT11 (счётчик ошибок, переинициализация)
- [x] Импульсное питание датчика воды (50 мс, защита от электролиза)
- [x] Стабилизация состояния датчика воды (5 секунд стабильности)

### Пользовательский интерфейс
- [x] 5 экранов на LCD дисплее:
  - Экран 0: температура и состояние форточки
  - Экран 1: влажность воздуха и статус
  - Экран 2: освещённость и состояние фитоленты
  - Экран 3: влажность почвы и состояние насоса
  - Экран 4: уровень воды в баке
- [x] Автоматическая смена экранов (каждые 3 секунды)
- [x] Безопасная печать (safePrint) — проверка состояния дисплея перед выводом

### Проектирование и документация
- [x] Разработана структурная схема теплицы (сенсорный, вычислительный, исполнительный блоки)
- [x] Собран действующий прототип (каркас + обшивка + электроника)
- [x] Написано 500+ строк кода с комментариями
- [x] Оформлена презентация для конференции
- [x] Репозиторий на GitHub (лицензия MIT)

### Экономическая эффективность
- [x] Рассчитана себестоимость (~4640 рублей)
- [x] Проведено сравнение с аналогами (Xiaomi Flower Care, «Умная грядка», Priva, OpenGrow)

- [ ] **Расширенная диагностика**
  - Тест всех датчиков при запуске

## 🔮 ПЕРСПЕКТИВНЫЕ ПЛАНЫ (2027 год)

Эти функции требуют больше времени и ресурсов.

### Удалённое управление и мониторинг
- [ ] **Wi-Fi модуль (ESP8266 / ESP32)**
  - Замена Arduino на ESP8266 (встроенный Wi-Fi)
  - Или добавление модуля ESP-01 через Serial

- [ ] **Telegram бот**
  - Управление теплицей через команды
  - Получение показаний датчиков
  - Уведомления о проблемах (нет воды, высокая температура)

- [ ] **Веб-интерфейс**
  - Графики температуры, влажности, освещённости
  - Управление поливом, светом, форточкой
  - Адаптивный дизайн (работает на телефоне)

### Умные алгоритмы
- [ ] **Библиотека растений (Plant Library)**
  - Выбор растения из меню на дисплее
  - Автоматическая настройка порогов под выбранную культуру
  - База параметров для 30+ растений

- [ ] **Автоматическая калибровка датчиков**
  - Обновление калибровочных значений при изменении условий
  - Запись в EEPROM

- [ ] **Прогнозирование полива по трендам**
  - Анализ скорости высыхания почвы
  - Прогнозирование времени следующего полива
  - Адаптация под погодные условия

- [ ] **Учёт стадий роста растения**
  - Рассада → Вегетация → Цветение → Плодоношение
  - Разные пороги для каждой стадии
  - Автоматический переход по таймеру

### Новые датчики
- [ ] **Датчик CO₂ (MH-Z19B)**
  - Контроль углекислого газа для фотосинтеза
  - Открытие форточки при низком CO₂

- [ ] **Датчик температуры почвы (DS18B20)**
  - Контроль прогрева корней
  - Защита от переохлаждения

- [ ] **Датчик протока воды**
  - Контроль реальной подачи воды при поливе
  - Обнаружение засора или воздушной пробки

### Интеграция с другими системами
- [ ] **Home Assistant (MQTT)**
  - Интеграция с экосистемой умного дома
  - Управление через единый интерфейс

- [ ] **Голосовые помощники (Алиса, Google Assistant)**
  - "Алиса, включи полив на 30 секунд"
  - "Google, открой форточку"

- [ ] **Мобильное приложение (Flutter)**
  - Кроссплатформенное приложение для iOS и Android
  - Пуш-уведомления о проблемах
